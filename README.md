Smart Password Authentication System Using 8051 Microcontroller

Project Overview

This project demonstrates a password-based security system using the 8051 microcontroller.

The system uses a keypad to enter a password and an LCD display to interact with the user. The entered password is checked by the microcontroller to determine whether access should be granted or denied.

This project was developed using an 8051 microcontroller trainer kit as a practical implementation of embedded systems concepts.

Components Used

- 8051 Microcontroller
- 16x2 LCD Display
- Matrix Keypad
- LEDs
- 8051 Microcontroller Trainer Kit
- Connecting Wires

Software and Tools

- Keil µVision
- Embedded C
- 8051 Microcontroller Programming

Working Principle

1. The system starts and displays a message on the LCD.
2. The user enters a password using the keypad.
3. The 8051 microcontroller reads the entered password.
4. The entered password is compared with the stored password.
5. Based on the result, the system indicates whether access is granted or denied.
